# react-mobile

React Native and mobile development tools and skills for Claude Code.

## What's inside

- `gluestack-ui` skill: how to add and use gluestack UI headless components in the mobile app.

## Use it

Install the plugin, then ask Claude to add a feature or refactor components in the mobile app; the `gluestack-ui` skill loads on its own.

```
claude plugin install react-mobile@lichens-ai-dev-tools
```
