# react-testing-library

Guide for testing React components, hooks and context with React Testing Library.

## Triggers

Loaded when writing or fixing tests for React components, custom hooks, context providers, forms, loading and error states, portals or Suspense, or when reviewing React tests for anti-patterns. Not for end-to-end tests.

## What it contains

- `SKILL.md`: core principles, setup, the component testing pattern, the `data-testid` rule, an anti-patterns table and a checklist. It is test-runner agnostic (Vitest or Jest).
- `references/hooks.md`: custom hooks with `renderHook`.
- `references/context.md`: providers, the `wrapper` option and a custom `render`.
- `references/forms.md`: inputs, submission and validation.
- `references/advanced.md`: loading states, error boundaries, portals, Suspense and timers.
