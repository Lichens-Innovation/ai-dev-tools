# react-testing

React testing tools and skills for Claude Code.

## What's inside

- `react-testing-library` skill: testing React components, hooks and context with React Testing Library (works with Vitest or Jest), including providers, forms, async UI, portals, and common anti-patterns.

## Use it

Install the plugin, then ask Claude to write or fix tests for a component, hook or context provider; the skill loads on its own.

```
claude plugin install react-testing@lichens-ai-dev-tools
```
