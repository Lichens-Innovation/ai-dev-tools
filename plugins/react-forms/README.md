# react-forms

React form tools and skills for Claude Code.

## What's inside

- `react-hook-form` skill: setting up react-hook-form with Zod validation in React.

## Use it

Install the plugin, then ask Claude to create a form, add validation, wire a Zod schema, or integrate react-hook-form with a UI library; the skill loads on its own.

```
claude plugin install react-forms@lichens-ai-dev-tools
```
