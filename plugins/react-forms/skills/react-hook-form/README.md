# react-hook-form

Guide for setting up react-hook-form with Zod validation in React.

## Triggers

Loaded when creating a form component, adding form validation, wiring Zod schemas to a form, using `Controller`, handling submission, displaying field errors, resetting or pre-populating a form, or integrating react-hook-form with a UI library (Ant Design, MUI, shadcn, etc.).

## What it contains

The `SKILL.md` covers the setup, typing form values with TypeScript, and the patterns above.
