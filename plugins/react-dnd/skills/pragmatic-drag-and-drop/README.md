# pragmatic-drag-and-drop

Guide for setting up `@atlaskit/pragmatic-drag-and-drop` in a React project and building drag and drop UIs with it.

## Triggers

Loaded when adding drag and drop to a React project, making a list reorderable, dragging items between lists, blocking invalid or duplicate drops, adding a drop zone, building a board or grid where items move between cells, or debugging any of these.

## What it contains

- `SKILL.md`: the base reorderable list pattern and when to use each reference.
- `references/setup.md`: packages to install and the shared helpers (drag state, drop state, instance context, reorder), needed once per project.
- `references/authorization.md`: drops from an external source with validation and visual feedback.
- `references/drop-zone.md`: a dedicated zone that appends external items.
- `references/board-example.md`: a grid where pieces move between cells (the library's chess example, condensed).
