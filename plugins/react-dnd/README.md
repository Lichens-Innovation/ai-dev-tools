# react-dnd

Drag and drop tools and skills for React, built on `@atlaskit/pragmatic-drag-and-drop`.

## What's inside

- `pragmatic-drag-and-drop` skill: installing the library in a React project, the shared helpers (drag state, drop state, instance context, reorder), and recipes for a reorderable list, cross-list drops with authorization, a drop zone, and a grid or board.

## Use it

Install the plugin, then ask Claude to add drag and drop to a project, make a list reorderable, drag items between lists, or build a board; the skill loads on its own.

```
claude plugin install react-dnd@lichens-ai-dev-tools
```
