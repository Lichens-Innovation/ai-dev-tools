# react-diagrams

React diagram and canvas tools and skills for Claude Code.

## What's inside

- `react-flow-canvas-geometry` skill: computing React Flow (@xyflow) canvas geometry correctly: edge label anchors, bezier control points, handle coordinates and node bounds.

## Use it

Install the plugin, then ask Claude to place or offset edge labels, reimplement `getBezierPath` maths, or debug an element that renders in the wrong place on the canvas; the skill loads on its own.

```
claude plugin install react-diagrams@lichens-ai-dev-tools
```
