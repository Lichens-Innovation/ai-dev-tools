# gluestack-ui

Explains how to use the gluestack UI library (headless components) in the mobile app.

## Triggers

Loaded when adding a new feature to the mobile app or refactoring its components.

## What it contains

The `SKILL.md` covers adding components with the gluestack CLI from `apps/mobile`, adding style tokens to a new component, and points to the offline gluestack v5 docs in `docs/gluestack-full-llm.md`.
