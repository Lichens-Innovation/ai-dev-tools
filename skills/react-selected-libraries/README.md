# react-selected-libraries

The preferred libraries for common React needs that are not worth a dedicated skill yet.

## Triggers

Loaded when choosing or adding a library to a React project (state store, server state, routing, tables, UI components, icons, i18n, rich text and Markdown, HTTP, dates, ids, utilities, class names, hotkeys, charts, visibility detection), or when writing code against one of them.

## What it contains

The `SKILL.md` has the rules for applying the list (an existing project's libraries win) and a table of the selected libraries with short usage notes, for example `zustand` for client state.

## Related

- `react-forms`, `react-dnd` and `react-testing` plugins: libraries with enough depth for their own skill
